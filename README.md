## 🚀 **Getting Started**

### **Prerequisites**
- Node.js 18+ 
- pnpm (recommended) or npm
- Git

### **Installation**

```bash
# Clone the repository
git clone https://github.com/luisalbertmschz/luisalbertms.dev.git

# Navigate to project directory
cd luisalbertms.dev

# Install dependencies
pnpm install

# Start development server
pnpm dev
```

### **Build & Deploy**

```bash
# Build for production
pnpm build

# Start production server
pnpm start

# Lint code
pnpm lint
```
